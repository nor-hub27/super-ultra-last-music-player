Music Player - Android app project

1. Create a free account at github.com and make a new repository (any name).
2. Upload everything in this folder to it, keeping the folders. These must all be at the top level:
   www, assets, native, .github, package.json, capacitor.config.json, make_icons.py
3. Open the "Actions" tab, choose "Build APK" on the left, then press "Run workflow".
4. When it finishes (about 5 minutes) open the run and download "music-player-apk" at the bottom.
5. UNINSTALL the old Music Player from your phone first (so the new icon shows), then install app-debug.apk.
